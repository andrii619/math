#### Excercise 2.10 Page 82

Prove the following. For each, m, n, and t are integers.

a) If $m|n$, then $m^2|n^2$

**Proof:**

Since $m|n$, then using the definition of integer divisibility, $n=mk$ for some integer k. Then $n^2=(mk)(mk) = m^2k^2$ by using the fact that $\mathbb Z$ is closed under multiplication and commutative property holds. Therefore, $m^2|n^2$ as needed.
$\square$

c) If $m|n$ and $m|t$, then $m|(n+t)$.

**Proof:**

If $m|n$ and $m|t$ then $n=mk$ for some integer $k$ and $t=ml$ for some integer $l$ by using the definition of integer divisibility. So $n+t=mk+lm=m(k+l)$. Hence, by also using definition of integer divisibility, $m|(n+t)$ as was required to show.
$\square$
